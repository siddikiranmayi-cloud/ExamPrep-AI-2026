# ExamPrep AI 2026

## Overview
ExamPrep AI is an AI-powered study assistant that helps students prepare for exams by generating summaries, quizzes, and answers from study materials.

## Features

### Summary Generator
Creates concise summaries from notes and study content.

### Quiz Generator
Generates multiple-choice questions for self-assessment.

### Question Answering
Answers student questions based on available learning materials.

## Technology Stack
- Python
- Streamlit
- OpenAI
- Microsoft Foundry IQ (Planned)
- Azure AI Services (Planned)

## Project Structure

app.py - Main application
